# Use cases

## Engineering Copilot

A utility engineer asks for an outage triage summary. grid-forge retrieves the outage SOP, transformer maintenance guide, and vegetation policy, then produces a grounded summary with safety caveats and citations.

## Regulatory Copilot

A regulatory analyst asks for a response memo for docket 24-017. grid-forge retrieves the regulatory order and related filings, drafts a memo, and records the source trail in audit events.

## Customer Ops Copilot

A customer operations rep pastes an inbound complaint. grid-forge classifies the issue, summarizes the problem, drafts a safe response, suggests escalation, and marks review-needed.

## Ops Manager Review

An ops manager reviews audit events to see which sources were used by copilots and whether any outputs required approval.
